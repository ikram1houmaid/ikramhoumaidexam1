Intitulé : Gestion des missions d’une entreprise
Description brève
Une entreprise de services souhaite développer une application Java pour gérer ses employés, ses projets et les missions réalisées.
L’application doit permettre de manipuler plusieurs types d’employés, d’affecter des missions à des projets, de calculer le coût de chaque mission et de gérer une relation hiérarchique entre employés. L’étude est basée sur les notions suivantes :
héritage ;
classe abstraite ;
polymorphisme ;
association entre classes ;
association réflexive ;
tableaux d’objets.
